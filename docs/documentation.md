# Documentation guide

[KiwiPi 5 Pro product page](https://kiwipi.com/product/kiwi-pi-5pro/) · [Official resources](https://kiwipi.com/document-center/?dc_tab=6896.1)

## Hardware and first setup

Start with the [user manuals](https://drive.google.com/drive/folders/1txRkogPIWy0VG9KGqm2bTIBfw65wT7H0) for power requirements, connector assignments and installation instructions applicable to your hardware revision.

Use the [schematics](https://drive.google.com/drive/folders/1eNvhZdmvuK6nfiCxvCA6Af7WLhnqKaKK) for electrical reference. Match the schematic revision to your board.

## Firmware installation

Choose a compatible image from [Downloads](downloads.md). Follow its firmware upgrade instructions and obtain tools from the [official development tools folder](https://drive.google.com/drive/folders/1DVUnC1cMh05vjd7bNXinoPWemwMSzoYS).

## Software development

Obtain SDKs and source archives from the [official source folder](https://drive.google.com/drive/folders/1RRd20IsdaQ3kOQqNCf0aSn6b_LFXwr5Q). Follow the selected SDK's build instructions and component licenses.

## Support

For help identifying the correct manual, hardware revision or firmware image, [contact KiwiPi](https://kiwipi.com/contact-us/).
